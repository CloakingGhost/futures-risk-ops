# futures-risk-ops (가칭 마진워치)

KIS(한국투자증권) Open API로 코스피200 선물 시세를 자기 PC에서 수집하고, 그 데이터로 증거금·마진콜 위험을 계산하는 셀프 호스팅 오픈소스다.
주문 기능은 없고, 키는 환경변수로만 읽는다. 지켜야 할 규칙과 명령은 [CLAUDE.md](CLAUDE.md), 개발 환경은 [docs/dev-setup.md](docs/dev-setup.md)에 있다.

## 모듈

| 모듈 | 하는 일 |
|---|---|
| `simulator` | KIS 형식의 가짜 체결·호가를 내보낸다. 키 없이 개발한다 |
| `db` | Flyway 마이그레이션 |
| `collector` | 근월물을 골라 실시간 체결·호가를 받아 PostgreSQL 에 쌓는다 |
| `risk` | 증거금·마진콜 계산(만드는 중) |

## 로드맵

- **v0.1 (30일)**: 코스피200 선물 하나(근월물)의 실시간 수집, 증거금·마진콜 계산, 대시보드·알람, 사람이 승인하는 AI 원인 분석.
- **옵션은 v0.1 범위에서 뺀다 (2026-10-29 결정)**: 옵션은 90일 범위로 미룬다. 옵션은 종목 수가 많고(행사가·콜/풋), 증거금 계산 방식이 선물과 다르며, instrument 에 행사가·콜풋 열도 없다. 그래서 v0.1 은 선물만 구독하고 근월물 선택·롤오버도 선물만 한다. instrument 의 `OPTION` 값은 남겨 둔다.
- **90일**: 옵션 체결·호가 구독, 옵션 증거금, 야간 호가(H0MFASP0).
