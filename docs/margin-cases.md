# 증거금 계산 사례

`risk` 모듈 `MarginCalculator` 가 이 문서의 표를 그대로 테스트로 읽는다(`MarginCasesTest`). 표를 고치면 테스트도 같이 바뀐다.
모든 숫자는 손으로 만든 합성값이다. 실제 계좌나 시세가 아니다.

## 계산 규칙

| 항목 | 규칙 | 근거 |
|---|---|---|
| 승수 | 1포인트 = 250,000원 | 코스피200 선물 거래승수 |
| 틱 | 0.05포인트 = 12,500원 | 코스피200 선물 호가 단위 |
| 손익 | 매수 +(현재가 - 기준가) x 계약 x 승수, 매도는 부호 반대 | |
| 기준가 | 처음에는 진입가, 일일정산 뒤에는 그날 정산가 | 선물은 매일 정산가로 손익을 예탁금에 반영한다 |
| 위탁·유지증거금 | 현재가 x 승수 x 계약 x 증거금률, 원 미만은 올린다 | 올림은 가정이다. 증거금을 적게 보이지 않으려고 보수적으로 잡았다 |
| 평가예탁금 | 예탁금 + 손익 | |
| 마진콜 | 평가예탁금 < 유지증거금 | 같으면 마진콜이 아니다(A10) |
| 추가납부액 | 위탁증거금 - 평가예탁금 | 추가증거금은 위탁증거금 수준까지 채운다([머니투데이 2015-01-08](https://www.mt.co.kr/stock/2015/01/08/2015010714390802312)) |
| 마진콜 가격 | 매수 (기준가 - 예탁금 / (계약 x 승수)) / (1 - 유지율), 매도 (기준가 + 예탁금 / (계약 x 승수)) / (1 + 유지율) | 평가예탁금 = 유지증거금이 되는 가격. 매수는 0.01 올림, 매도는 0.01 내림(경고가 늦지 않게). 매수에서 0 이하면 없음 |
| 남은 폭 | 매수 현재가 - 마진콜 가격, 매도 마진콜 가격 - 현재가. 이미 마진콜이면 0 | 포인트 단위 |

기본 증거금률은 위탁 21.750%, 유지 14.500% 다(한국투자증권, 2026년 10월 기준, 사용자 확인 2026-10-30). 거래소가 거의 매달 바꾸므로 값은 `risk` 설정(`risk.margin.*`)에만 두고, 사례는 비율을 직접 적는다.

v0.1 은 단일 선물 포지션만 계산한다. 옵션, 스프레드, 포트폴리오 증거금, 거래소 공식 정산가는 다루지 않는다.
