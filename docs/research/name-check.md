# 이름 확인 기록 — 가칭 마진워치

- 확인일: 2026-10-26
- 이 기록은 **참고용 검색 결과**이고 법적 판단이 아니다. 상표 등록 가능성과 유사 여부는 변리사 확인 사항이다.

## KIPRIS 국내 상표 (사용자 직접 검색, 화면 캡처 기준)

| 검색어 | 결과 |
|---|---|
| 마진워치 | 국내 상표 0건 (권리구분 전체 체크, 15:43 캡처) |
| 마진 워치 | 없음 (사용자 보고) |
| marginwatch | 검색결과 없음 |
| MarginWatch | 검색결과 없음 |

아직 안 한 것: 해외 탭, 발음이 비슷한 표기(마진와치 등), 상품류 지정(9류 소프트웨어·36류 금융·42류 SaaS), 영문 상표 데이터베이스(WIPO 등)

## GitHub (저장소 이름 검색, API)

- `marginwatch` 이름 검색 10건 이상, `margin-watch` 이름 검색 17건. 대부분 소매·재고·SaaS 마진 분석이고, 별 0~1개.
- 영역이 가까운 것: [joshwg/MarginWatch](https://github.com/joshwg/MarginWatch) — "Specialized option margin computation for systematic writing" (옵션 마진 계산, 별 0, 2026-09-28 갱신)
- 우리 저장소 이름은 `futures-risk-ops`라서 위 이름과 겹치지 않는다. 서비스 이름을 쓸 때만 겹침이 문제가 된다.

## 웹 검색

- "마진워치": 같은 이름의 국내 서비스는 검색되지 않음(일반 마진 거래 앱 글만 나옴)
- "MarginWatch": 같은 이름의 금융 소프트웨어는 못 찾음. FXCM의 "Margin Watcher"처럼 비슷한 기능 이름이 있음

## 정리

- 국내 KIPRIS에서는 0건이지만, **margin + watch는 일반적인 단어 조합**이고 GitHub에 같은 이름이 많다. 이 이름이 식별력이 있는지, 영문 이름이 해외에서 막히는지는 변리사에게 물어볼 항목이다.
- 결정할 것: (1) 가칭을 유지하고 공개(Day 5) 전에 해외 탭과 유사 표기까지 다시 확인 (2) 후보 이름을 몇 개 더 만들어 같은 방식으로 검색
