# KIS 에 대해 확인한 것과 가정

| 항목 | 내용 | 확인 여부 |
|---|---|---|
| 주간 체결 H0IFCNT0 | 모의투자 주간장에서 실제로 수신됨(2026-10-28). KIS 공식 문서에는 "모의 미지원"이라 적혀 있음 | 실수신 확인 |
| 종목코드 형식 | 주간 `A01612` 형식이 통함 | 실수신 확인 |
| 야간 체결 H0MFCNT0 | 별도 TR. Day 3 에서 세션별 구독 전환으로 처리. 야간 마스터 `fo_cme_code.mst` 도 A01612 형식이라 tr_key 도 A01612 로 가정 | 가정, Day 3 마감 때 야간 수집은 사용자 확인 |
| H0MFCNT0·H0IFASP0 | KIS 문서상 '모의 미지원' | 문서 기준 |
| 주간 1~4계약 빈틈 | 연결 중 생기는 작은 빈틈은 KIS 가 묶어서 보내는 것으로 추정 | 미확정 |
| 체결 메시지 12~14번 | hts_thpr·mrkt_basis·dprt. mrkt_basis = 선물 − 지수 | 가정 |
| 접속키 만료 | 24시간으로 가정, 지표로만 감시, 자동 재발급 없음 | 가정 |
| 마스터 다운로드 | 클라우드·디바이스 VM 모두 403 → 사용자가 직접 받아 `margin-watch\ref` 에 둠 | 확인 |
| 마스터 형식 | `fo_idx_code_mts.mst.zip`, cp949, `|` 구분, 월물구분코드 1=최근월물 | 확인 |
| 체결 조회 TR | 이름에 '주문' 포함 → 절대 규칙 1 때문에 쓰지 않음 | 사용자 결정 |
| 야간 체결 H0MFCNT0 tr_key | 실전에서 `A01612` 로 실제 수신됨(2026-11-16 23:35 부터, source=KIS, NIGHT) | **실수신 확인(2026-11-17)** |
| 접속키 만료 | 유효 24시간. 연결할 때 한 번만 쓰므로 연결이 이어지는 동안 만료는 상관없다 | **공식 문서 확인(2026-11-17)** |
| 접근토큰(`/oauth2/tokenP`) | 유효 24시간, 6시간 안에 다시 요청하면 직전 토큰을 돌려준다. 그때도 `expires_in` 은 86400 이고 실제 만료는 `access_token_token_expired`(한국 시각) | **공식 문서 + 실호출(2026-11-17)** |
| 일봉 `FHKIF03020100` | 종목코드 `A01612` 로 받아진다. 시장 코드 F(주간) 5·15영업일 성공, 영업일 수와 행 수 일치 | **실호출 확인(2026-11-16)**, 자세한 내용 [kis-daily-bar.md](../kis-daily-bar.md) |
| 일봉 시장 코드 `CM` | 명세에 `CM: 야간선물` 이라고만 있다(약자 풀이 없음). F 와 다른 별도 시리즈이고 날짜는 야간장이 열린 날로 보이며 진행 중인 값이 온다 | 실호출 확인(2026-11-16), 날짜 기준은 추정. v0.1 에서는 쓰지 않는다 |
| 일봉 `mod_yn` | 전체 문서(332 시트)에도 설명이 없다. 받은 행은 모두 `N` 이었다 | 뜻 미상, 값만 보관 |
| 일봉을 주간장 기준으로 보는지 | 종가는 일치. 거래량은 일봉이 마지막 체결 누적보다 1.424% 큼. 야간 합산은 아님(야간 18.6%에 못 미침). 원인 미상 | **미판정**(기준 1% 초과), 11/18 에 한 번 더 |
| 일봉 확정 시점 | 마감 15분 뒤(15:59:59) 받은 값이 22분 뒤 받은 값과 같다 | **확인(2026-11-17)** |
| 종가 단일가 | 15:34:59 다음 체결이 15:45:00(단일가 한 번에 일봉 거래량의 약 2.3%). 그 10분은 체결이 없다 | **관찰(2026-11-17)** |

필드 상세는 `docs/kis-h0ifcnt0.md` 를 본다.
