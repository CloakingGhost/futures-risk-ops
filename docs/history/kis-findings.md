# KIS 에 대해 확인한 것과 가정

| 항목 | 내용 | 확인 여부 |
|---|---|---|
| 주간 체결 H0IFCNT0 | 모의투자 주간장에서 실제로 수신됨(2026-10-28). KIS 공식 문서에는 "모의 미지원"이라 적혀 있음 | 실수신 확인 |
| 종목코드 형식 | 주간 `A01612` 형식이 통함 | 실수신 확인 |
| 야간 체결 H0MFCNT0 | 별도 TR. Day 3 에서 세션별 구독 전환으로 처리. 야간 마스터 `fo_cme_code.mst` 도 A01612 형식이라 tr_key 도 A01612 로 가정 | 가정, Day 3 마감 때 야간 수집은 사용자 확인 |
| H0MFCNT0·H0IFASP0 | KIS 문서상 '모의 미지원' | 문서 기준 |
| 주간 1~4계약 빈틈 | 연결 중 생기는 작은 빈틈은 KIS 가 묶어서 보내는 것으로 추정 | 미확정 |
| 체결 메시지 12~14번 | hts_thpr·mrkt_basis·dprt. mrkt_basis = 선물 − 지수 | 가정 |
| 접속키 만료 | 24시간으로 가정, 지표로만 감시, 자동 재발급 없음 | 가정 |
| 마스터 다운로드 | 클라우드·디바이스 VM 모두 403 → 사용자가 직접 받아 `margin-watch\ref` 에 둠 | 확인 |
| 마스터 형식 | `fo_idx_code_mts.mst.zip`, cp949, `|` 구분, 월물구분코드 1=최근월물 | 확인 |
| 체결 조회 TR | 이름에 '주문' 포함 → 절대 규칙 1 때문에 쓰지 않음 | 사용자 결정 |

필드 상세는 `docs/kis-h0ifcnt0.md` 를 본다.
